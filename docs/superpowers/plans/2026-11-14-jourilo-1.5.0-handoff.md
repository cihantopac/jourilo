## Process for the next release (Cihan, 2026-11-14)

1.4.0 took about two days (15 tasks, a review agent and fix rounds per task, full ci after almost every commit). Cihan
asked for a much lighter process: "agent işi yapar sana gönderir sen bakar alırsın bu kadar basit".

- Small releases: 5–6 tasks. No tasks added mid-release unless a real field bug.
- One implementer per task; it runs focused tests only. No reviewer agents: the controller reads the diff and the report,
  accepts it or sends one short fix back to the same implementer.
- Minors go straight to the next version's list.
- Full `npm run ci` and `npm run bench` once, before push. No final whole-branch review agent.
- Skip ACT and extra real-project runs unless the release touched their area.
- Push, PR, merge after green CI (Cihan reports CI; no polling, no auto-merge), tag and GitHub release are routine.
  npm publish stays Cihan's: `git checkout vX.Y.Z` → `npm publish --access public` (no `--otp`) → `git switch main`.

## Lessons

- TypeScript 7 is the Go port and has no JS compiler API. The parser is TypeScript 6.0.3 through the exact alias
  devDependency `"typescript-js": "npm:typescript@6.0.3"`, bundled as the lazy chunk `plugin/dist/ts-parser.mjs` (D21);
  `typescript` 7 stays for `tsc`.
- biome formats Markdown too: run `npx biome format --write .` after doc edits, or ci fails on formatting.
- GitHub macOS runners are the slowest: the widgets-lab fixture test takes ~110 s on Linux CI and timed out at 120 s on
  macOS (now 300 s). Give large fixture tests headroom.
- Timeout flakes locally came from overlapping heavy runs (16 GB Mac). One ci/bench/browser run at a time; they pass
  alone.
- Windows CI: environment variable names are case-insensitive; keys for adapters are read from the environment only.
- npm login expires; if `npm publish` says 401/404, Cihan runs `npm login` first.
- On macOS `localhost` resolves to `::1` first; the net guard now tries every checked address (5 s each, 30 s total).

## Rulings from 1.4.0 that still bind

- R1/R2: TS 6.0.3 parser via `typescript-js`, reached through one dynamic `import()` loader (lazy chunk).
- R6: analytics adapter fixtures are synthesized from vendor docs (no live accounts); say so wherever results are
  claimed.
- Scroll-padding fixer falls back to a conventional global CSS file name when the product profile names none.
- Axe and every Jourilo probe run through `page.evaluate` (not governed by CSP); `bypassCSP` stays off so real site CSP
  defects are still reported. Jourilo's own console noise is dropped by the `jourilo-inpage://` sourceURL marker
  (`src/browser/own-activity.ts`).

## Candidates for 1.5.0 (deferred minors)

Cihan (2026-11-14) chose to close all of them in 1.5.0: see the [1.5.0 plan](2026-11-14-jourilo-1.5.0.md) (one
branch, one PR, one commit per task).

**Higher value**

- Italian "Ordina per prezzo" and "Comprare casa" / "Compra de ingressos" are refused as financial actions (false
  refusal, fail-safe).
- `isMinified` (`/^.{2000}/m`) sends hand-written files with one long line to the regex fallback; `.svelte` has no
  regex, so its routes are lost.
- Sequential test: an arm with almost no visitors gives a far too small p-value; consider a minimum-n floor.
- Amplitude cannot detect a missing third arm of a multi-arm experiment.
- `--proxy` opens its tunnel to the first allowed address only (in LIMITATIONS).
- WebKit: Jourilo's own style refusal during a screenshot is dropped only by time window.
- Component graph parse cost unmeasured on a large repository (~7 s extrapolated at the 6000-file cap); code files are
  read twice.
- F43 optional warning when the workspace is inside `--repo`.
- 1.3.0: contrast sampling worst case ~2 min per capture — add a total time budget; scrolling to nodes can trigger
  lazy-load before later captures.
- 1.3.0: an unusable proxy env (e.g. socks5) fails every run with exit 2; the hint should name `NO_PROXY=*`.

**Menus and widgets**

- `settle()` misses a role-less popup without `aria-expanded` that ignores Escape (cookie banners).
- Menu cap of 4 is counted before the destructive/financial name filter; re-tag after reload assumes stable DOM order.
- Disclosure loop can cost up to 2 s per unfocusable trigger.
- menu-navigation test does not assert the link menu was opened; `checkMenus` has bench-only coverage.
- `visible()` helper duplicated three times.

**Journeys**

- Chromium navigation without a Referer started by another frame may be judged same-site (documented limitation).
- An aborted mid-chain hop waits the full step timeout; step block attribution stops after 200 requests.
- Domain cookie on a trailing-dot host withheld (fail-closed); empty `cookie:` header sent when none qualifies.
- Referrer on the final page is the redirecting URL.

**Findings, trends, reports**

- `changed` always fires when a collapse appears in only one run; a redirected page's location is not normalized to
  `{page}`.
- Trends: LCP/CLS from the first capture only; no note when the page set changes between runs.
- Fixer evidence for `button-implicit-submit` has no rect or screenshot.
- `dynamic` Turkish rule-text list has no completeness test.
- Net guard: budget exhaustion between attempts reports the previous attempt's code, not timeout.

**Tests and docs (1.3.0 leftovers)**
