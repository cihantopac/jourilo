# Requirements and quality targets

## Product requirements

| Area                 | Requirement                                                                                                                                                                     | Status (1.0.0)                                    |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------- |
| Modes                | Repository mode (source + local run) and Website mode (URL only, no source assumptions)                                                                                         | Done                                              |
| Product intelligence | Frameworks, routes, components, design system, i18n, auth, payments, analytics, flags, roles, monorepos; website pages, conversion points, services; facts labelled with source | Done (lexical; Laravel route files/groups/panels) |
| Journeys             | Suggested from evidence; JSON with explicit success criteria; runnable with step evidence; safety policy                                                                        | Done (no multi-tab; --repeat flake detection)     |
| Browser              | Real browser, screenshots, traces, console and network errors, viewports, keyboard-only, deterministic data, controlled retry                                                   | Done (Chromium, Firefox, WebKit tested in CI)     |
| UX/UI quality        | WCAG 2.2 AA automated + manual-review list; keyboard; target size; reflow; forms; responsive; lab Web Vitals; design-system consistency                                         | Done for listed checks                            |
| Conversion           | CTA, value proposition, trust, form friction, pricing; hypotheses separated from defects                                                                                        | Done (heuristic)                                  |
| Repair               | Locate sources, minimal fixes, diffs, apply with checkpoint, verify, rollback                                                                                                   | Done (7 fixers, transactions, safe rollback)      |
| Experimentation      | Sample size, plans with metrics/guardrails/stopping rule, analysis with CI and SRM                                                                                              | Done (two-proportion only)                        |
| Observatory          | HTML report with annotated screenshots, reproduction, sources, journeys, before/after; Markdown; SARIF                                                                          | Done (history table; no normalized trends)        |
| Integrations         | Optional Markilo and Searvex via versioned contract                                                                                                                             | Done (read-only)                                  |
| Distribution         | CLI independent of Claude Code; Claude Code plugin calling the real toolchain; adapters for other agents                                                                        | Done                                              |

## Measurable quality targets

| Target                                                   | Threshold                                                                                                           | How it is checked                                              | Current                                        |
| -------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------- | ---------------------------------------------- |
| Seeded-defect recall on fixtures                         | 100 %                                                                                                               | `jourilo bench` (CI gate via `tests/browser/fixtures.test.ts`) | 43 / 43                                        |
| False positives on the clean control (moderate or worse) | 0                                                                                                                   | same                                                           | 0                                              |
| Root-cause file accuracy on fixtures                     | 100 % of declared expectations                                                                                      | same                                                           | 9 / 9                                          |
| Repair loop                                              | verify shows every applied fix as fixed and 0 new serious defects; re-apply is a no-op; rollback restores all files | `tests/browser/repair.test.ts`                                 | passes                                         |
| Safety policy                                            | payment/destructive steps blocked by default (any interaction mechanism); allowed only on local with flag           | `action-safety.test.ts`, `tests/unit/journeys.test.ts`         | passes (12 adversarial journeys)               |
| Network safety                                           | public targets cannot reach loopback/LAN/metadata through any browser request                                       | `tests/browser/net-guard.test.ts` (3 engines)                  | passes                                         |
| Data safety of audits                                    | audits and form probes send no data-changing request without `--allow-submit`                                       | `action-safety.test.ts` (persistent store)                     | passes                                         |
| Rollback                                                 | never overwrites edits made after a change; byte-exact; interrupted applies recoverable                             | `tests/unit/git.test.ts`                                       | passes                                         |
| Clean install                                            | every advertised command works from the packed tarball                                                              | `scripts/smoke-pack.mjs` (CI, 3 platforms)                     | passes                                         |
| Report safety                                            | untrusted strings never produce markup or script                                                                    | `tests/unit/report.test.ts`                                    | passes                                         |
| Audit time                                               | ≤ 60 s for 6 pages × 2 viewports on a local site                                                                    | bench timings                                                  | ~32 s (acme-saas, 6 pages, 2 viewports, forms) |
| Statistics                                               | sample sizes within ±2 of reference values; distribution functions to 5 decimals                                    | `tests/unit/experiment.test.ts`                                | passes                                         |
| Plugin                                                   | manifests pass `claude plugin validate --strict`; every skill command exists                                        | CI `plugin` job, `tests/unit/plugin.test.ts`                   | passes                                         |
