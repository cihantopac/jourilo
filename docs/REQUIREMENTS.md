# Requirements and quality targets

## Product requirements

| Area                 | Requirement                                                                                                                                                                     | Status (0.1.0)                                   |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------ |
| Modes                | Repository mode (source + local run) and Website mode (URL only, no source assumptions)                                                                                         | Done                                             |
| Product intelligence | Frameworks, routes, components, design system, i18n, auth, payments, analytics, flags, roles, monorepos; website pages, conversion points, services; facts labelled with source | Done (lexical; no AST)                           |
| Journeys             | Suggested from evidence; JSON with explicit success criteria; runnable with step evidence; safety policy                                                                        | Done (no multi-tab, no auth bootstrap)           |
| Browser              | Real browser, screenshots, traces, console and network errors, viewports, keyboard-only, deterministic data, controlled retry                                                   | Done (Chromium tested; Firefox/WebKit untested)  |
| UX/UI quality        | WCAG 2.2 AA automated + manual-review list; keyboard; target size; reflow; forms; responsive; lab Web Vitals; design-system consistency                                         | Done for listed checks                           |
| Conversion           | CTA, value proposition, trust, form friction, pricing; hypotheses separated from defects                                                                                        | Done (heuristic)                                 |
| Repair               | Locate sources, minimal fixes, diffs, apply with checkpoint, verify, rollback                                                                                                   | Done (5 deterministic fixers + agent-made fixes) |
| Experimentation      | Sample size, plans with metrics/guardrails/stopping rule, analysis with CI and SRM                                                                                              | Done (two-proportion only)                       |
| Observatory          | HTML report with annotated screenshots, reproduction, sources, journeys, before/after; Markdown; SARIF                                                                          | Done (no historical trend view yet)              |
| Integrations         | Optional Markilo and Searvex via versioned contract                                                                                                                             | Done (read-only)                                 |
| Distribution         | CLI independent of Claude Code; Claude Code plugin calling the real toolchain; adapters for other agents                                                                        | Done                                             |

## Measurable quality targets

| Target                                                   | Threshold                                                                                                           | How it is checked                                               | Current                                        |
| -------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------- | ---------------------------------------------- |
| Seeded-defect recall on fixtures                         | 100 %                                                                                                               | `jourilo bench` (CI gate via `tests/browser/fixtures.test.ts`)  | 25 / 25                                        |
| False positives on the clean control (moderate or worse) | 0                                                                                                                   | same                                                            | 0                                              |
| Root-cause file accuracy on fixtures                     | 100 % of declared expectations                                                                                      | same                                                            | 9 / 9                                          |
| Repair loop                                              | verify shows every applied fix as fixed and 0 new serious defects; re-apply is a no-op; rollback restores all files | `tests/browser/repair.test.ts`                                  | passes                                         |
| Safety policy                                            | payment/destructive steps blocked by default; allowed only on local with flag                                       | `tests/browser/journeys.test.ts`, `tests/unit/journeys.test.ts` | passes                                         |
| Report safety                                            | untrusted strings never produce markup or script                                                                    | `tests/unit/report.test.ts`                                     | passes                                         |
| Audit time                                               | ≤ 60 s for 6 pages × 2 viewports on a local site                                                                    | bench timings                                                   | ~32 s (acme-saas, 6 pages, 2 viewports, forms) |
| Statistics                                               | sample sizes within ±2 of reference values; distribution functions to 5 decimals                                    | `tests/unit/experiment.test.ts`                                 | passes                                         |
| Plugin                                                   | manifests pass `claude plugin validate --strict`; every skill command exists                                        | CI `plugin` job, `tests/unit/plugin.test.ts`                    | passes                                         |
